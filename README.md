# 🚀 vanilla-http

A lightweight, dependency-free JavaScript library for making HTTP requests using **XMLHttpRequest** and **Fetch API** — all in one place.

---

## 📦 Features

- ✅ Supports GET, POST, PUT, DELETE  
- ✅ Works with both **XMLHttpRequest** and **fetch**  
- ✅ Promise-based API  
- ✅ Small & framework-free  
- ✅ Works in any modern browser
